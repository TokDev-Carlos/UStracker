# Glossário — UStracker

- **Adm Global:** dono do sistema (Token Mestre + PIN); ativa computadores e cria o Administrador.
- **Administrador / Adm Local:** administra a empresa naquela instalação.
- **Pacote:** conjunto de permissões de um usuário (Gerente, Operador…).
- **Placa:** `placa.json` com os bancos (Apps Script) da empresa.
- **Token Mestre / acesso-UStracker:** repositório privado com as chaves do Adm Global.
- **Frota / Mobilidade:** veículos agrupados por empresa do cliente.
- **Assinatura:** plano mensal recorrente; **Compra direta:** venda avulsa.
- **Competência:** mês de referência de uma cobrança.
- **Tempo ativo / Cobertura:** período de serviço registrado sem cobrança.
- **Canal (`updates/`):** onde as instalações procuram atualização.
- **`.usup`:** pacote de atualização assinado; **`.uspatch`:** `.usup` + `update.json` para o Aplicador.
- **Época:** número da "vida" da empresa na nuvem (2.5); muda quando a empresa é zerada.
- **Varredura:** checagem do instalador que separa dados antigos não validados.
