# tools

- `generate_sbom.py`: lista de componentes (SBOM.json) do pacote.
- `package.ps1`: monta a pasta do programa no Windows.
- `publish_update.py`: publica uma versão no canal `updates/` (assina com a chave da pasta Tokens/UStracker do Google Drive).
- `sync_version.py`: copia `version.md` para `VERSION.json` e `current.json`.
